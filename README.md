## Featured project

### [Red Hawk Wallet](https://github.com/harshvk8/redhawkwallet-flutter)

A collaborative campus commerce and student wallet project built with Flutter.

**My contributions — Flutter UI and user experience**

- Contributed in vendor browsing screens, plus demo interfaces for sending money, receiving money, and paying vendors.
- Developed student screens for the dashboard, account profile, university verification, QR ID/scanner previews, and transaction history/details.
- Created reusable widgets for back navigation and loading, empty, error, and retry states.
- Connected dashboard and account actions to their destinations, reducing navigation dead ends across student, vendor, and admin screens.
- Improved dark-mode support by replacing hard-coded colors with theme-aware styling across wallet, vendor, and settings screens.
